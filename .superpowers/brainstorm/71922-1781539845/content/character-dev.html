A — Evolution Tree

Choose a form path as you level up. Classic → Burning, or Armored → Mech-Fused. Each branch changes your FPS abilities and what you see in first-person (body, hands, HUD color).

B — Stats + Skills RPG (Recommended)

Traditional RPG sheet: STR, DEF, SPD, RAGE, INT. Spend points each level, unlock ability slots. Food you eat raises specific stats. Conquering cities unlocks new abilities to slot in.

C — City Reputation System

No stat points — instead each city has a reputation meter. Destroy everything → FEARED (power boost, enemies flee). Spare survivors → REVERED (healing buffs, intel). Changes the FPS experience in each city.
