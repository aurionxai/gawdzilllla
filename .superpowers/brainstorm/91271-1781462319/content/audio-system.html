🎙️ Audio Upload Portal (in-game dev tool)

Upload Interface
Drag-and-drop MP3/WAV → auto-mapped to city/character by filename. Preview plays in browser. Live reload — no rebuild needed.
Subtitle System
Each voice line shows the native script + English translation on screen for 2 seconds. Configurable font per language (supports CJK, Arabic RTL, Devanagari).
AI Voice Generation
For launch: generate all 50 power-up lines + character voices using ElevenLabs or similar TTS. Upload as MP3s. Replace with real recordings any time.
Funny Extra Lines
Each city also has 3 random "funny" variants — e.g. Tokyo: "も一度！" (One more time!) or NYC: "I'm walkin' here!" as Godzilla steps on a taxi.

All 50 city voice lines generated via AI TTS at launch, swappable anytime via upload. Does this audio architecture work? ✅
