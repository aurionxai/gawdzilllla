# Kaiju Clash — Concept Mockups

Generated via Higgsfield (`nano_banana_pro`), ~2 credits / 1K image.
On-model approach: existing hero sprites imported as reference for consistency.

## Locked art direction
- **16-bit SNES pixel art** — vibrant, clean, kid-friendly, crisp pixels, side view.
- Heroes shown across the **5-stage growth spine**: Hatchling → Juvenile → Adolescent → Leviathan → Apex.
- Lulah = feminine: green body, **pink/magenta glowing frills**, red bow, soft round happy face.
- Poppy = golden **ape/Kong-style** kaiju, pink flower, rosy cheeks, friendly grin.
